# UI 平台适配与会话功能审校 — 2026-11-03

> 触发：用户指出「各系统客户端 UI 没有各自适配，会话功能体验差」。
> 结论：**批评成立**。以下为现状盘点、差距清单、可借鉴项目与升级提案。

---

## 一、三套前端 UI 适配现状（欠账盘点）

| 前端 | 文件 | 规模 | 适配问题 |
|---|---|---|---|
| 桌面（Electron+Vue） | renderer/css/style.css | 271 行 | **仅暗色主题硬编码**（--bg:#0f1115），无浅色模式、无 nativeTheme 跟随系统、无平台差异（macOS 红绿灯 / Windows 关闭键 / Linux 原生滚动条） |
| Web（飞牛/浏览器） | server/static/{chat,admin,share}.html + 门户内嵌 | ~1800 行 | **仅浅色主题硬编码**，夜间刺眼；三页各自维护一份 :root 变量，无共享 design tokens |
| Android App | mobile/www/index.html | 195 行 | **只有一张「连接卡片」**：无设备发现列表、无会话页、无投送面板，全靠跳系统浏览器，等于"壳"而非客户端 |

已做的移动适配（chat.html）：成员抽屉、safe-area、PWA manifest、iOS 安装引导——这块及格。

**根因（诚实交代）**：v1.10→v1.14 五个版本全压在协议链路上（投送协议、会合点、分块中继、UPnP、安全热修），UI 一直沿用 v1.0 的"能用占位"，没有单独立项。取舍成立，但账确实欠下了。

## 二、会话功能差距清单

现有：文本/文件/文件夹/粘贴/拖拽/输入状态/成员聚合/清空/音视频通话/屏幕共享/历史分页。

缺失（按痛感排序）：

**P0（半成品与硬伤）**
1. **撤回无入口** — 服务端 `chat.recall` 已实现，客户端没有任何按钮（半成品实锤）
2. **无消息状态** — 发送中/失败/重发全没有，WS 断线期间发的消息直接丢
3. **无未读反馈** — 无角标、无标题栏计数、无声音；Notification 点击不聚焦窗口
4. **上传不可取消** — 单条聚合进度条、无逐文件进度、失败不重试
5. **身份脆弱** — localStorage 随机 ID+随机名，换浏览器/清缓存就"换人"

**P1（体验差距）**
6. 无私聊/@指定成员（`chat.send` 是纯广播）
7. 无引用回复、无表情、URL 不自动成链接、图片查看器无缩放手势
8. 无消息搜索、无导出；recall 时 renderAll 全量重绘（消息多了会卡）
9. 桌面端内嵌会话页与浏览器页共享服务端但无跳转互通入口

**P2（能力扩展）**
10. 跨设备（@前缀成员）通话不支持（代码里有 alert 提示"后续版本"）
11. 屏幕共享无声音；通话状态不广播给未入会成员
12. 无 Markdown/代码块；移动端键盘弹起遮挡输入框未处理

## 三、可借鉴项目

| 项目 | 借鉴点 | 对应差距 |
|---|---|---|
| **LocalSend** | 协议互通（v2 路线已列）、设备改名/头像颜色哈希 | 差距 5、富身份 |
| **PairDrop** | 6 位配对码 + 常驻设备置顶 + 临时房间；匿名→常驻身份的平滑过渡 | 差距 5 |
| **KDE Connect** | 剪贴板同步（本项已有雏形 clip.sync）、通知同步、手机当触控板 | P2 方向 |
| **LANDrop** | 跨网段发现（本项目会合点方案已覆盖并超出） | — |
| **Feem** | 断点续传 UX：逐文件进度 + 暂停/恢复按钮 | 差距 4 |
| **Rocket.Chat / Mattermost** | 自托管 IM 的消息 UX：撤回/编辑/引用/搜索/Markdown 全套 | 差距 6-12 |
| **croc / magic-wormhole** | PAKE 口语验证码（"3 个词"配对），比 PIN 数字体验好 | 投送 PIN 增强 |
| 微信/Telegram（UX 参考，非开源） | 消息状态、撤回交互、通知点击定位 | 差距 1-3 |

## 四、升级提案（待确认后开工）

**v1.15.0 — UI 适配专场**
1. 共享 design tokens（三端同一份 CSS 变量）
2. 桌面端浅色/深色双主题 + nativeTheme 跟随系统 + 平台标题栏差异（macOS traffic lights / Win 右侧按钮）
3. Web 端暗色主题 + 手动切换（localStorage 记忆）
4. Android App 二期：设备发现列表 + 直投面板 + 会话页 WebView（不再只跳浏览器）

**v1.16.0 — 会话增强专场**
1. P0 全项：撤回入口、消息状态（送达/失败重发）、未读角标+通知聚焦、上传取消+逐文件进度、稳定身份（deviceId 绑定）
2. P1 选做：@私聊、引用回复、URL 链接化、消息搜索

预计 v1.15 约 5 项改动三前端联动，v1.16 涉及 server/chat.js 协议扩展 + 三端。
